# 物理のアトリエ

高校物理の体験型学習サイトのトップ画面。React + Viteで作成。

## 開発

```sh
npm install
npm run dev
```

`npm run build` で `dist/` に本番用ファイルを出力します。

## 現在の範囲

- 指定の学習指導計画に基づく５分野・14章・48セクションの冒険マップ
- 各章の名称、セクション番号・学習項目、学習のねらい・関連実験を表示
- 全48セクションに対応する用語解説ページ、セクション別一覧、検索・分野絞り込み
- マップ・セクション詳細から用語へ移動できるリンク（用語ページのURL共有とブラウザーの戻るにも対応）
- PDFシラバスのA〜H等の小単元168項目を、既存48セクションの下に対応付け
- 小単元ごとの目標・関連用語・３段階の振り返りと、ノートへの記録
- 単元ごとの３段階の理解レベルを選べる詳細画面
- 速度と加速度の導入〇×クイズ、理由入力、フィードバック、振り返り
- ブラウザー内への学びのノート保存とテキスト出力
- 復習画面とスマートフォン対応

教材本編、シミュレーション、理解度判定、自動復習スケジュール、他者との共有は今後実装します。マップの到達度表示は未学習の初期状態です。ノートは同じブラウザーのlocalStorageに保存し、アカウント間・端末間では同期しません。

## 小単元の資料と対応

`src/subunits.json` は、東京書籍「物理」（物理701）の `rika_16630_syllabus.pdf` にある小単元名・学習目標・出典ページを保持します。従来の数研出版のExcelとは節構成が異なるため、サイトの章・セクションIDは維持し、複数のPDF節を収める箇所は元の節名も表示します。剛体のBは内容が二つのサイト内セクションにまたがります。「波と媒質の運動」はPDFのA項目を捏造せず、サイトで補った復習として明示しています。配置は合計170件です。

小単元の３段階表示は、本人が振り返りを記録した段階を示すもので、自動採点・習得判定ではありません。記録は従来の `physics-notes` と同じブラウザー内ストレージに保存します。
